    await test.step('Solicitar la cotización a Bruno', async () => {
  await page.getByRole('button', {

    03 / LEÉ LA EVIDENCIA
    Cada concepto con su valor.
    
          
    La cotización usa una lista de definiciones: los conceptos tienen rol term y sus valores,
            definition. Comprobá ambas listas ordenadas dentro del diálogo. La cantidad también debe coincidir.
    
          
    const cotizacion = page.getByRole('dialog', {
  name: 'Confirmar transferencia',
});
await expect(cotizacion.getByRole('term')).toHaveText([
  'Importe', 'Comisión', 'Total a reservar',
]);
await expect(cotizacion.getByRole('definition')).toHaveText([
  '$ 100,00', '$ 1,00', '$ 101,00',
]);
    
          
    toHaveText([...]) reintenta hasta encontrar la lista esperada. Un valor presente en cualquier lugar
            o un aviso genérico no comprueban el desglose. La interfaz presenta ARS; fill('100') recibe pesos.
    
          
    Después de cerrar el diálogo, await page.reload() vuelve a leer el estado desde el servidor.
            Comprobá diaria $ 2.500,00, ahorro $ 600,00 y que todavía no haya transferencias.
            Cerrar una cotización no es cancelar una transferencia pendiente.
    
          
    npx playwright test transfer-quote.spec.js --headed
npm run report
