    03 / COMPROBÁ EL RECHAZO
    No inventes un mensaje de error.
    
          
    validationMessage es una propiedad del campo HTML, no un atributo ni un texto de la página.
            Si está vacío, el control no informa una restricción incumplida. Comprobamos que no esté vacío, sin depender de su redacción:
    
          
    await expect(importe)
  .not.toHaveJSProperty('validationMessage', '');
await expect(dialogo).toBeVisible();
await expect(importe).toBeFocused();
    
          
    Después verificá $ 2.500,00 dentro de diaria y $ 600,00 dentro de ahorro.
            Comprobar solo los saldos podría aprobar mientras una operación todavía está en curso.
            Primero necesitás evidencia del rechazo. No agregues waitForTimeout().
    
          
    Esta prueba cubre la validación de la interfaz. No demuestra que el servidor rechace solicitudes manipuladas:
            esa responsabilidad necesita sus propios tests de API. No quites required ni min
            desde el test para hacer pasar este recorrido.
    
          
    npx playwright test invalid-deposit.spec.js --headed
npm test
npm run report
    
          
    Este archivo debe mostrar 3 passed; la suite acumulada, 10 passed.
            Al sumar el reto, serán 11 passed.
