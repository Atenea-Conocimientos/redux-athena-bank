    03 / LEÉ LA EVIDENCIA
    Probá también el fallo.
    
          
    Desde la terminal del repo de automatización, con el banco encendido en otra terminal:
    
          
    npx playwright test first-test.spec.js --headed
npm run report
    
          
    Primero hacelo pasar. Después cambiá únicamente el texto esperado del título por
            Bienvenido al banco y ejecutá de nuevo: debe fallar. Compará Expected
            con Received. Restaurá el texto correcto del requisito y volvé a ejecutar.
    
          
    En la escena del fallo, usamos 1 segundo de timeout para capturar el diagnóstico rápidamente.
            Tu proyecto usa 7 segundos por defecto. No necesitás cambiarlo ni agregar una espera fija.
